## Ver 0.8 (2026.11.03)

### 궁수 2차 전직
- 2레벨 직업 선택을 1차 전직으로 표시.
- 궁수 30레벨 달성 시 2차 전직 확인창 표시.
- 전직 선택 중 게임 일시정지.
- ‘나중에’ 선택 시 기존 스킬을 유지하고 재진입 버튼 제공.
- 2차 전직 확정 시 기존 Z 관통 스킬을 끄고 새 Z/X/C 스킬과 회피 사격 활성화.
- 기존 자동 평타 유지.
- 캐릭터 정보창에 ‘2차 궁수’ 표시.

### Z — 부채꼴 연사
- 발동 순간 조준 방향을 고정하고 관통 화살 12발을 순서대로 발사.
- 전체 발사 각도 50도, 발사 간격 0.035초.
- 기본 피해량은 발당 6, 쿨타임은 6초.
- 화살은 돌과 나무에 막히도록 처리.
- 실제 화살 발사마다 단발 효과음을 중첩 재생하는 기능 추가.
- Inspector에서 단발 음원과 볼륨 설정 가능.

### X — 화살비
- 가까운 적의 발동 당시 위치에 원형 장판 생성.
- 적이 없으면 마지막 이동 방향의 3 거리 앞에 생성.
- 장판 위치는 발동 후 고정.
- 기본 지속 시간 2.5초, 반경 2.5.
- 0.25초마다 범위 내 적에게 피해 2 적용.
- 쿨타임은 8초.

### C — 크리스탈 애로우
- 장애물을 통과하는 거대 얼음 화살 발사.
- 적 명중 시 직격 피해와 범위 폭발·기절 적용.
- 기본 직격 피해 25, 폭발 피해 12, 폭발 반경 3, 기절 1.5초.
- 폭발 후 화살 8발이 퍼지고, 명중 시 각각 3발로 분열.
- 다음 명중 시 다시 각각 3발로 분열하며 최대 3단계에서 종료.
- 기본 분열탄 피해는 5, 쿨타임은 20초.
- 분열탄은 장애물에 막히며, 같은 분열 경로에서 앞 단계가 맞힌 적을 다시 타격하지 않도록 처리.

### Shift — 회피 사격
- 2차 전직 이후 대쉬 시작 지점에서 이동 반대 방향으로 화살 3발 발사.
- 기본 전체 발사 각도 24도, 발당 피해 6.
- 회피 사격 화살은 적을 관통하지 않음.
- 이동 방향 대쉬와 정지 시 마지막 이동 방향 사용 유지.
- 최대 3개 충전, 3초마다 1개 회복하는 기존 대쉬 충전 공유.
- 기존 대쉬 거리·효과음·적 관통·접촉 피해 방지 유지.
- 대쉬 한 번에 사격이 한 번만 발생하도록 연결.

### 스킬 화살 크기 조절
- Z 연사와 C 최초 거대 화살은 Arrow Scale로 크기 조절.
- X 화살비에 Arrow Scale 설정 추가.
- C 첫 분열탄에 Scatter Scale 설정 추가.
- C 후속 분열탄은 Split Scale Falloff 비율을 단계마다 곱해 크기 조절.
- 이미지 크기 변경 시 피해량과 타격 판정 범위는 유지.

### HUD 및 동작 보완
- 2차 전직 후 HUD의 Z/X/C 슬롯을 새 스킬과 연결.
- Shift 슬롯의 기존 충전 표시 유지.
- 빠른 스킬 화살이 적이나 장애물을 건너뛰지 않도록 이동 구간 충돌 검사 보완.
- 사망 시 진행 중인 연사·화살비를 중단하고 남은 스킬 투사체 정리.
- 씬 재시작 시 전직·스킬 상태 초기화.
- 30레벨을 기다리지 않고 2차 전직창을 열 수 있는 테스트 메뉴 제공.
- 3·4차 전직, 보스, 스탯·증강 기능은 이번 활성화 범위에서 제외.

## Ver 0.6 (2026.10.19)

### 게임오버 후 재시작
- 게임오버 상태에서 R키를 누르면 현재 씬을 다시 시작하도록 구현.
- 재시작 시 체력·레벨·경험치·직업·대쉬 충전을 초기 상태로 복구.
- 게임오버 화면에 R키 재시작 안내 표시.

### 전체화면 및 창모드 전환
- F11키로 전체화면과 창모드를 전환하는 기능 추가.
- 전체화면은 테두리 없는 전체화면 방식 사용.
- 창모드 기본 해상도는 1280×720으로 설정.
- Inspector에서 전환 키와 창모드 해상도 변경 가능.
- 게임오버 및 전직 선택 중에도 화면 모드 전환 가능.
- Unity 에디터에서는 전환하지 않으며 빌드한 실행파일에서 사용.

### 장애물 랜덤 생성 좌표값 수정
- 기존 랜덤 장애물이 배치될 좌표의 x축과 y축을 일관적이지 않도록 수정.

### 스택형 대쉬
- Shift키로 대쉬 사용.
- 시작 시 대쉬 3개 보유, 최대 3개까지 충전.
- 대쉬 사용 시 충전 1개 소비.
- 3초마다 대쉬 1개씩 순차 충전.
- 충전 중 대쉬를 사용해도 진행 중인 충전 시간 유지.
- 이동 방향으로 대쉬하며, 정지 상태에서는 마지막 이동 방향으로 사용.
- 대쉬 중 적을 관통하고 적 접촉 피해를 받지 않도록 처리.
- 돌과 나무의 장애물 충돌은 유지.
- 게임 일시정지 중에는 대쉬 사용과 충전도 정지.
- 화면에 남은 대쉬 개수와 다음 충전까지의 시간 표시.

### 대쉬 사운드
- 대쉬가 실제로 발동할 때 효과음을 재생하는 기능 추가.
- Inspector에서 대쉬 음원과 볼륨 설정 가능.

### 캐릭터 좌우 방향 전환
- A키 또는 왼쪽 방향키 입력 시 왼쪽을 바라보도록 처리.
- D키 또는 오른쪽 방향키 입력 시 오른쪽을 바라보도록 처리.
- 위아래 이동 및 정지 상태에서는 마지막 좌우 방향 유지.
- 대기 이미지와 공격 이미지에 동일하게 좌우 반전 적용.
- 원본 이미지가 바라보는 방향을 Inspector에서 설정 가능.
- 교체 코드 작성 완료, 실제 프로젝트 적용은 미확인.

### 궁수 화살 이미지 적용

## Ver 0.3

### 청크 기반 맵 로딩
- 플레이어가 있는 청크와 주변 8개 청크를 불러오도록 구현.
- 이동에 따라 새로운 청크를 생성하고 멀어진 청크는 제거.
- 카메라에 보이는 영역이 청크 한 칸보다 작도록 크기 조절.

### 돌·나무 랜덤 배치
- 청크 안의 지정된 위치마다 나무·돌·없음 중 하나를 랜덤으로 선택.
- 생성 확률: 나무 30%, 돌 30%, 없음 40%.

### 장애물 충돌
- 돌과 나무의 충돌 영역을 이미지 형태에 맞게 조절.
- 나무의 잎 부분은 통과할 수 있고, 기둥 부분은 통과할 수 없도록 설정.
- 플레이어와 적이 장애물을 통과하지 못하도록 처리.

### 적의 장애물 우회 길찾기
- 적이 장애물에 막혀 멈추지 않고 우회하여 플레이어에게 접근하도록 구현.
- 여러 적이 경로 정보를 공유하도록 구성.
- 플레이어가 장애물에 붙었을 때 발생하던 과도한 경로 탐색 횟수를 줄여 최적화.

### 자동 공격의 가까운 적 우선순위 강화
- 공격 방향을 결정할 때 가까운 적에 더 큰 가중치를 부여.
- 가까운 적을 우선하는 정도를 설정값으로 조절할 수 있도록 구현.

### 맵, 장애물 이미지와 표시 순서
- 나무 이미지를 본체와 그림자로 분리.
- 나무의 잎 부분이 캐릭터 앞에 표시되도록 구성.
- 그림자는 캐릭터 아래에, 나무 본체는 위에 표시하도록 구성.
- 해당 버전 기준으로 실제 프로젝트 적용은 미완료.
